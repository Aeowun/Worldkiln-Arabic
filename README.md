# وورلد كيلن — التوثيق العربي (Worldkiln)

**Worldkiln** محرك ألعاب ومحرّر لإنشاء ألعاب ثلاثية الأبعاد على Windows. يمكنك بناء العوالم باستخدام **Cells**، وتشكيل التضاريس، واستيراد الأصول ثلاثية الأبعاد، وكتابة منطق اللعب بلغة **AeoScript**، ثم تصدير ألعاب مستقلة لنظام Windows.

> **تنبيه بشأن الترجمة:** أنا مطوّر Worldkiln، **ولا أتحدث العربية**. أُعدّت هذه الوثائق بمساعدة الذكاء الاصطناعي، وقد تحتوي على أخطاء لغوية أو تقنية. إذا وجدت خطأً أو شرحًا غير واضح، **يُرجى إرسال طلب سحب (Pull Request)** لتصحيحه. مساهمات المتحدثين بالعربية مرحّب بها.
>

## أبرز الميزات

- **بناء العوالم:** بناء المنشآت باستخدام Cells، ونحت التضاريس وطلائها، وإعداد المواد والإضاءة والسماء والضباب.
- **المياه التفاعلية (BETA):** أمواج وتموجات وآثار الحركة والرغوة وتأثيرات الكاميرا تحت الماء.
- **الكائنات والشخصيات:** استيراد نماذج GLB، ووضع Actors في المشهد، واستخدام Characters متحركة.
- **برمجة اللعب:** لغة AeoScript للتفاعل، والفيزياء، والتنقل، والواجهات، والصوت، والكاميرات.
- **التجربة والتصدير:** تشغيل اللعبة باستخدام وضع **Play** داخل المحرّر، ثم إنشاء نسخة مستقلة من خلال **Build Game**.

تُشير علامة **BETA** إلى ميزة لا تزال قيد التطوير.

## المتطلبات والتنزيل

وفقًا للوثائق الرسمية، يعمل Worldkiln على **Windows 10 وWindows 11**.

1. افتح [صفحة الإصدارات الرسمية](https://github.com/Aeowun/Worldkiln/releases).
2. نزّل برنامج التثبيت المناسب وأي أصول اختيارية تحتاجها.
3. ثبّت Worldkiln وشغّله.
4. أنشئ مشروعًا جديدًا داخل المحرّر.

لشرح الخطوات، راجع [دليل البدء العربي](GETTING_STARTED.md) أو [الدليل الرسمي باللغة الإنجليزية](https://aeowun.com/worldkiln/getting-started/).

## صيغ الاستيراد

### النماذج والشخصيات

| الصيغة | الحالة حسب وثائق Worldkiln V1 |
| --- | --- |
| `.glb` | مدعومة؛ الصيغة الموصى بها |
| `.fbx` | لا يوجد استيراد مباشر في الوثائق المرجعية؛ حوّلها إلى GLB |
| `.obj` | لا يوجد استيراد مباشر؛ حوّلها إلى GLB |
| `.gltf` | استخدم GLB بدلًا منها |
| `.blend` | صدّر من Blender إلى GLB |

يمكن أن يحتوي ملف GLB الواحد على النموذج والمواد والخامات والهيكل العظمي والرسوم المتحركة. قد تحتاج بعض الشخصيات إلى تعديل بيانات التحريك أو الهيكل بعد الاستيراد.

### الصور والأصوات والوسائط

| النوع | الصيغ المذكورة في التوثيق الرسمي |
| --- | --- |
| الصور والخامات | `.png` و`.jpg` و`.jpeg` |
| الصوت | `.wav` و`.mp3`؛ وتتوفر `.ogg` في بعض مسارات إدارة الأصول |
| الفيديو | `.mp4`؛ يعتمد التشغيل على الترميز والنظام |
| المؤثرات المرئية | `.efkefc` و`.efkpkg` من Effekseer |

لا يعني امتداد الملف المدعوم أن جميع الملفات بهذا الامتداد ستُستورد بنجاح؛ فقد تكون هناك قيود متعلقة بالمحتوى أو بالتوافق.

## تحويل النماذج إلى GLB

عندما يكون النموذج بصيغة FBX أو OBJ أو Blender:

1. افتح النموذج في [Blender](https://www.blender.org/).
2. افحص الخامات والاتجاه والرسوم المتحركة.
3. اختر **File → Export → glTF 2.0**.
4. اختر **glTF Binary (.glb)** وصدّر الملف.
5. استورد ملف GLB الناتج إلى Worldkiln.
